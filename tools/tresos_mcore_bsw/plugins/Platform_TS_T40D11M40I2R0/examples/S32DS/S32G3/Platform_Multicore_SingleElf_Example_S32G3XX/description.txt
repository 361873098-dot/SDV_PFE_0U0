1. Example Description
    This application demonstrates the usage of a subset of Real Time Drivers.
    The application includes an S32DS project that configures the Dio EcuC Gpt Mcu Os Platform Port BaseNXP.
    This is a simple application which shows the usage of multicore feature with single binary file on S32DS for S32G399 derivative.
    Each core will configure and use its resources to blink 2 LEDs continuously with 1Hz frequency in PIT/STM interrupt.

2. Installation steps
    2.1 Hardware installation
        2.1.1 Hardware preparation
            - S32G-VNP-RDB3 PCB 53060 RevC SCH RevF, S32G3 silicon (Rev 1.1)
            - P32G399AACVUC SBAU2235 1P72B TIAUSBA
        2.2.2 Connections
            - Connect S32 debugger to the board
        2.2.3 Debugger
            - S32 debugger
    2.2 Software installation
        2.2.1 Importing the S32 Design Studio project
            Make sure that all RTD plugins are already installed in the S32DS plugins directory

3. How to run
    3.1 Importing the project into the workspace
        After opening S32 Design Studio, go to "File -> New -> S32DS Project From Example" and select "Platform_Multicore_SingleElf_Example_S32G3XX". Then click on "Finish".
        The project should now be copied into you current workspace.
        Wait for the S32 Configuration was initialized and ready.
    3.2 Generating the S32 configuration
        The example will run without an active configuration, however if any changes are required, a configuration needs to be generated.
        The initial configuration will have the same settings as the default example settings.
        Right click on the current project, then click "S32 Configuration Tool" choose "Open Clocks".
        Pay attention to any error and warning message. If any configured value is invalid, they will be shown for user.
        Make the desired changes (if any) then click "Update Code".
    3.3 Building the project
        Select the configuration to be built: RAM (Debug_RAM) by left clicking on the downward arrow corresponding to the build button in eclipse.
        Use Project > Build to build the project.
        Wait for the build action to be completed before continuing to the next step. Check the compiler console for error messages; upon completion, the *.elf binary file should  be created.
    3.4 Running the project
        Go to Run and select Debug Configurations. There will be a debug configuration for this project:
        Configuration Name                                                  		   Description
        -------------------------------                                     		   -----------------------
        Platform_Multicore_SingleElf_Example_S32G3XX_M7_0_Debug_RAM_S32Debug           Debug the RAM configuration on the core M7_0 using S32Debug probe
        Platform_Multicore_SingleElf_Example_S32G3XX_M7_1_Debug_RAM_S32Debug		   Debug the RAM configuration on the core M7_1 using S32Debug probe
        Platform_Multicore_SingleElf_Example_S32G3XX_M7_S32Debug_group                 Debug with an group of both RAM configurations above using S32Debug probe
        
        Select group debug configuration Platform_Multicore_SingleElf_Example_S32G3XX_M7_S32Debug_group and click on Debug. Now the perspective will change to the Debug Perspective.
        Use the controls to control the program flow.

Note: restrictions on opening Disassembly window while debugging. This will cause connection error to core.
